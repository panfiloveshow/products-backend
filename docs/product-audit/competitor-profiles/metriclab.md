# MetricLab

Источник: [официальная API-документация](https://web.metriclab.ru/api-doc/), проверено 29 июля 2026 года.

## Позиционирование

Аналитическая платформа и публичный API для расчёта потребности WB/Ozon.

## Подтверждённая логика

- `POST /v1/{wb,ozon}/supplies`;
- WB: артикул+размер × федеральный округ;
- Ozon: SKU × кластер;
- потребность, остаток, средние продажи/заказы, прогноз выкупов, оборачиваемость;
- параметры горизонта, lead time, роста спроса, метода расчёта и кратности.

Публичная базовая формула:

```text
raw = среднесуточное × (planning_days + lead_time) × (1 + demand_growth)
need = round_to_pack(max(0, raw − stock))
```

## Значение для Sellico

Нужна такая же ясность параметров и формул, но продукт должен идти дальше: свежесть, ограничения, бюджет, подтверждение, исполнение и план-факт.
