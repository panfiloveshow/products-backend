# Мастер Поставки

Источник: [официальный сайт](https://masterpostavki.ru/), проверено 29 июля 2026 года.

## Позиционирование

Автоматический расчёт объёмов и создание поставок напрямую через Ozon API.

## Подтверждённые возможности

- расчёт Ozon FBO;
- распределение по складам/кластерам;
- учёт динамики;
- создание поставки через API;
- уведомления.

## Значение для Sellico

Показывает, что пользователь платит за доведение рекомендации до действия. Ozon preview → confirm → draft должен стать центральным премиальным сценарием, а не скрытым техническим endpoint.
